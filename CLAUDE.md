# Планировщик — веб

Личный планировщик задач. iPhone 16 как основное устройство, мак как второе. Плиточный борд: важность задаёт размер плитки, срочность — цвет, состояние — серая она или живая.

## Стек

Vite + React 18 + TypeScript strict, Tailwind 4 поверх CSS-переменных темы, Supabase (`supabase-js`), Dexie для офлайна, `@dnd-kit/core` для перетаскивания, Recharts для графиков.

## Структура

```
src/
  domain/     чистая логика, ноль зависимостей и ноль импортов
    themes/   реестр тем, чистые данные
  data/       Dexie, синхронизация, клиент Supabase, push, contract.ts
  ui/         переиспользуемые компоненты
  screens/    экраны
  app/        каркас, роутинг, провайдеры
  styles/     tokens.css
```

## Что нельзя ломать

- **Календарные даты — строки `'YYYY-MM-DD'`, никогда не `Date`.** Время — строка `'18:30'`. Настоящий момент собирается только в напоминаниях и статистике.
- **`src/domain/` не импортирует ничего.** Ни React, ни Supabase, ни Dexie. Только чистые функции со стопроцентным покрытием.
- **Состояние и срочность — разные оси.** `expired` проверяется раньше `slipped` — порядок в `taskState` часть контракта.
- **Просроченное не красное.** Красный означает «срок сегодня».
- **Срочность не хранится в БД** — считается из `due_on` при каждом рендере.
- **Ни один цвет не пишется в компонент напрямую.** Только токены (`var(--u4)` / Tailwind-классы поверх них). Источник истины — реестр `src/domain/themes/`; блок тем в `styles/tokens.css` обязан совпадать с ним.
- **Слетевшая задача остаётся на своём старом дне.** Полоса «Висят» — фильтр, а не копия.
- **Удаление мягкое, через `deleted_at`.**
- Грабли iOS перечислены в ТЗ §8 — не убирай `100dvh`, `overscroll-behavior`, `touch-action: none` на плитках, задержку 200 мс у PointerSensor.

## Команды

```
npm run dev        разработка
npm test           тесты
npm run typecheck  проверка типов
npm run coverage   покрытие домена (порог 100%)
```

Перед коммитом прогоняй `npm test` и `npm run typecheck`.

## Как работаем

Коммиты маленькие, по одной теме, сообщения по-русски в повелительном наклонении. Новые зависимости — только спросив. Абстракций на будущее не пишем. Закомментированный код не оставляем. Репозиторий публичный: секретам, ключам и личным данным здесь не место — публикуемый ключ Supabase не секрет, вся безопасность на RLS.
